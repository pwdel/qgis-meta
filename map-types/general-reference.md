# General reference

Status: starter editorial profile, 2026-10-09. Resource selections are candidates, not universal approvals.

Orientation, location, and regional context in interactive or printed maps.

## Resource pointers

| Resource | Role and limits |
| --- | --- |
| [Natural Earth](../resources/natural-earth.md) | Regional/world context and overview insets; evaluate dataset scale. |
| [OpenStreetMap data](../resources/osm-data.md) | More detailed geographic context, subject to data-license and quality review. |
| [OSM standard raster tiles](../resources/osm-standard-tiles.md) | Interactive basemap candidate only after endpoint review; no offline packaging. |
| [QGIS Style Hub](../resources/qgis-style-hub.md) | Discover styles; review the selected item. |
| [ColorBrewer](../resources/colorbrewer.md) | Choose palettes appropriate to the mapped variables. |

## Decisions for each map

Record extent, audience, scale, coordinate reference system, source dates, boundary interpretation, and publication mode. Test labels and attribution in the final output. Choose a source permitting offline use if needed.

Follow the [governance decision record](../GOVERNANCE.md) in the map project. Source selection and review dates belong to that concrete map.
