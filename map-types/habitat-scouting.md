## Decisions for each map

Select ecology and observation sources separately for the actual species, place, and period. Record evidence dates, methods, uncertainty, and any model limitations. Distinguish observations from predictions in the legend. Review precision of publicly shared locations and obtain separate evidence for any access claim.

Follow the [governance decision record](../GOVERNANCE.md) in the map project. Source selection and review dates belong to that concrete map.
