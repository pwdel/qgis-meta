# Trail and hiking

Status: starter editorial profile, 2026-10-09. Resource selections are candidates, not universal approvals.

Recreation, trail context, and route-planning maps; each project must determine its navigational fitness.

## Resource pointers

| Resource | Role and limits |
| --- | --- |
| [OpenTopoMap](../resources/opentopomap.md) | Terrain background candidate; check raster-service migration, attribution and acquisition limits. |
| [Mapbox Outdoors](../resources/mapbox-outdoors.md) | Legacy terrain-style candidate via WMTS/XYZ; token, billing, endpoint and output rights need review. |
| [OpenStreetMap data](../resources/osm-data.md) | Candidate trail context; assess completeness, currency, and local evidence. |
| [OSM standard raster tiles](../resources/osm-standard-tiles.md) | Online context only within service terms; unsuitable for offline packaging. |
| [NPS pictographic symbols](../resources/nps-symbols.md) | Discover recreation symbols; exact package terms remain unresolved. |
| [QGIS Style Hub](../resources/qgis-style-hub.md) | Discover line and point styles; review each selected item. |
| [Natural Earth](../resources/natural-earth.md) | Overview inset only; not detailed trail evidence. |

## Decisions for each map

Record route-source dates, terrain/elevation sources if used, distance units, map scale, closure evidence, and output mode. Select a separately permitted offline source before building an offline product. Land-manager sources and detailed terrain data are project-specific additions, not supplied by this profile.

Follow the [governance decision record](../GOVERNANCE.md) in the map project. Source selection and review dates belong to that concrete map.
