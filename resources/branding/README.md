# Rapid Water Labs brand artwork

`rapidwaterlabs.png` is the unchanged image supplied by the user on 2026-10-09.
It is brand artwork, not an open-source cartographic symbol. Rights are reserved
by its owner; the repository's code license does not grant rights to this logo.

The winter map composes the image with a native circular QGIS shape, preserving
its proportions and colors. Each project must bundle and register its own local
copy, with a SHA-256 checksum; do not link to a Desktop file or another repository.
The shared validator supports declared local PNG layout pictures and native
shapes with supported symbol layers. Other picture formats remain blocked.
Circular picture clipping uses QGIS 4.2 native picture-to-shape clipping. The
consumer must pin a compatible runtime; the source image remains unmodified.
