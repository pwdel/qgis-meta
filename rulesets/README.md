# Rulesets

These pages connect source-backed requirements to map decisions. They are human-readable indexes, not an automated permissions system.

| Ruleset | Scope |
| --- | --- |
| [Resource use and attribution](resource-use.md) | Licenses, endpoints, export, offline use, and provenance |
| [Readable styles and symbols](readable-styles.md) | Palette semantics, redundant visual cues, and artifact selection |
| [Place and activity evidence](place-and-activity.md) | Local editorial separation of mapped evidence and access decisions |

Each rule labels its origin. See [governance](../GOVERNANCE.md) for review states and conflict handling.
