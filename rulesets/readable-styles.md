# Readable styles and symbols

Reviewed 2026-10-09. Applies to cartographic presentation across the starter profiles.

| Rule | Origin | Scope and evidence |
| --- | --- | --- |
| Match palette semantics to ordered, diverging, or categorical data | Published guidance | [ColorBrewer](../resources/colorbrewer.md) |
| Do not rely on color alone to convey meaning in web maps | External standard | [WCAG use of color](../resources/wcag-use-of-color.md); one criterion, not full conformance |
| Also check non-color cues in printed maps | Local editorial recommendation | Adaptation of the web principle; not a claim WCAG directly governs print |
| Prefer an existing suitable style or symbol before creating one | Local editorial recommendation | Discover through [QGIS Style Hub](../resources/qgis-style-hub.md) and [NPS symbols](../resources/nps-symbols.md); item terms still need review |
| Test labels, symbols, and legend at the intended scale and output size | Local editorial recommendation | A resource's availability does not establish legibility |

For implementation guidance, consult the [QGIS style library](../resources/qgis-style-library.md) for the relevant software version.
